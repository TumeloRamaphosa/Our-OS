# Our-OS — Unified Studex Group Operating System

**Master control center for 1,056+ agents, $191M+ operations, 100+ websites**

## 🏗️ Architecture

```
OUR-OS (Master Repo)
├── dashboards/          (Web control center)
├── agents/              (Super Agents orchestration)
├── dark-factory/        (Site/agent generation)
├── operations/          (Meat, Coffee, Wheat verticals)
├── microservices/       (Google Cloud services)
├── infrastructure/      (Herdr, Buzz, Models House)
└── deployment/          (Cloudflare, Vercel configs)
```

## 🚀 Quick Start

```bash
# Clone all components
git clone https://github.com/TumeloRamaphosa/studex-coffee.git
git clone https://github.com/TumeloRamaphosa/studex-dashboards.git

# Deploy to Cloudflare
npm run deploy:cloudflare

# Start local dev
npm run dev
```
